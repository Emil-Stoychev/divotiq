# Дивотия

Модулна платформа за парти игри на български — Коледа, рожден ден, класическо парти, игри с пиене, семейни вечери или свой режим. Компанията играе на **едно устройство**: телефонът/лаптопът се подава на играча, чийто ред е.

- **Без регистрация** — цялата игра работи като гост и се пази в браузъра (оцелява презареждане).
- **С профил** — запазени игри и компании, история с хронология, собствено съдържание, свои режими и споделяне в библиотеката на общността.

---

## Функционалност

### Създаване на игра (wizard)
1. **Повод** — 6 вградени режима (Коледа, Рожден ден, Класическо, С пиене, Семейно, Свой) + собствените режими на потребителя + запазени игри. Режимът задава тема, предложени модули и рундове.
2. **Играчи** — 2–20 играчи с аватари, подреждане, запазени компании (с профил).
3. **Модули** — включване/изключване на 9-те модула; показва минимален брой играчи и предупреждения.
4. **Настройки** — общи правила (как се избира съдържанието на хода, ред на играчите, край — рундове/време/ръчно, точкуване, тема) и панел за всеки модул: колело (сегменти и тежести), собствено съдържание („Напиши свое“ или „От библиотеката“).
5. **Преглед** — проверка за проблеми, запазване за по-късно (лично/публично), старт.

### Модули
| Модул | Какво прави |
|---|---|
| 🎡 Колело на късмета | Анимирано колело с тежести; решава кой модул следва. Резултатът се изчислява от engine-а, анимацията само го показва. |
| 🎯 Предизвикателства | Задачи с таймер, точки, трудност, продължаващи ефекти. |
| 🎧 Whisper Challenge | Скрита фраза („задръж, за да видиш“), таймер, точки за отгатване. |
| 🎁 Подаръци и награди | Пул от физически подаръци с рядкост, мистериозни кутии, размяна. |
| 🍀 Карти късмет | Обръщане на карта: бонус/кражба на точки, имунитет, пропуск на ход, размяна и др. |
| 🌀 Продължаващи ефекти | Правила, които траят N хода; панел с активните ефекти. |
| 🕵️ Тайни мисии | Тайно връчване на всеки играч, домакинът отбелязва изпълнение; разкриване в края. |
| 🥃 С пиене | Глътки с **задължителна безалкохолна алтернатива**. |
| 🧠 Мини игри | Въпроси (trivia), пантомима, песни, рисуване, бързи думи. |

### По време на игра
Лента с рунд/ход и индикатор за синхронизация, пауза (спира таймерите), пропускане на модул, класиране с общи места при равенство, панели за ефекти, мисии, подаръци и история, звуци (WebAudio, без файлове), намалено движение, край → обобщение (подиум, класиране, статистика, подаръци, мисии), „Играй отново“.

### Профил и общност
- Регистрация/вход (JWT в HttpOnly cookie, bcrypt), профил, аватар, смяна на парола, изтриване на профил (с парола).
- **Моите игри**: запазени конфигурации (играй, редактирай, дублирай, лична/публична, изтрий) и история (продължи незавършена, детайли с хронология). Гост игра, завършена преди вход, се качва в профила след вход.
- **Моето съдържание**: 13 типа съдържание с валидация по тип, лично или публично.
- **Моите режими**: свои поводи с тема, предложени модули и рундове.
- **Библиотека**: търсене, филтри (тип, трудност, таг), подреждане, любими, копиране в своето съдържание, докладване; публични готови игри. Администраторът вижда докладваното и може да го скрие.

## Структура

```
divotiq/
├── .env.example          # всички променливи на средата
├── docker-compose.yml    # по желание: Postgres в Docker (profile docker-db)
├── justfile              # dev / test / build команди
├── server/               # Go 1.26 · Fiber v3 · Ent ORM · PostgreSQL
│   ├── main.go, routes.go
│   ├── database/         # Ent схеми (schema/) и генериран код (gen/)
│   ├── middleware/       # auth (JWT cookie), rate limit
│   ├── routes/           # auth, account, content, configs, modes, playerLists, sessions, admin
│   ├── services/         # валидация на съдържание/игри, seed данни (+ тестове)
│   ├── helpers/, utils/
│   └── cmd/apitest/      # end-to-end smoke тест срещу работещо API
└── web/                  # React 19 · Vite · Sass (BEM) · nanostores
    └── src/
        ├── game/         # чист JS engine — без React
        │   ├── engine/   # applyAction reducer, seeded RNG, draft, selectors, timers
        │   ├── modules/  # 9-те модула (registry)
        │   ├── modes/    # режими и теми
        │   ├── content/  # вградено съдържание и типове съдържание
        │   └── __tests__/
        ├── components/   # ui/, setup/, play/, modules/ (UI регистър), content/, game/
        ├── pages/        # Home, Setup, Play, Summary, Library, Dashboard, MyContent, ...
        ├── layouts/, hooks/, api/, sound/
        ├── utils/stores/ # auth, draft, session (+ sync), settings, router, ...
        └── resources/scss/
```

**Как работи играта:** цялото състояние е един JSON snapshot, който се променя само през `applyAction(state, action)` — чист reducer със seeded RNG и защита от двойни действия (action id). Затова играта е детерминистична, оцелява презареждане и се тества без браузър. С профил snapshot-ът се синхронизира с оптимистично версиониране (`baseVersion` → 409 при конфликт), а събитията от историята се записват идемпотентно.

## Стартиране

Изисквания: **Go 1.26+**, **Node 18+**, **PostgreSQL 14+** (локален или Docker), по желание [`just`](https://github.com/casey/just).

```bash
cp .env.example .env
```

Задължително сменете `SECRET` (поне 32 символа):

```bash
openssl rand -base64 36
```

### База данни
**Локален Postgres** (напр. Homebrew):

```bash
createuser divotiq --pwprompt
```

```bash
createdb -O divotiq divotiq
```

**или Docker** (тогава `DB_PORT=5434` в `.env`):

```bash
just db
```

Таблиците се създават/мигрират автоматично при старт на API-то (Ent auto-migrate). При първи старт се зареждат примерно съдържание от автора „Общността“ и (ако са зададени `ADMIN_EMAIL`/`ADMIN_PASSWORD`) администраторски профил.

### Разработка

```bash
cd web && npm install
```

```bash
just dev
```

или поотделно `just api` (http://127.0.0.1:3095) и `just web` (http://localhost:5190; Vite проксира `/api` към API-то).

### Променливи на средата
| Променлива | Описание |
|---|---|
| `SECRET` | Ключ за JWT, мин. 32 символа |
| `VITE_API_PORT` | Порт на API-то (3095) |
| `VITE_SITE_URL` | Адрес на сайта (CORS) |
| `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` | Връзка с PostgreSQL |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | По желание: администратор за модерация |
| `SEED_COMMUNITY_PASSWORD` | По желание: позволява вход като „Общността“ |

### Build

```bash
just build
```

Създава `server/divotiq-api` и `web/dist/`.

## Тестове

```bash
just test
```

- **web** (`vitest`, 44 теста): engine — начално състояние, детерминизъм, игнориране на повторени/остарели действия, ходове и рундове, пауза, ръчен край, презареждане (JSON round-trip); колело (резултат = анимация, изключени модули, еднократни сегменти); валидация на draft; всички модули (таймер, имунитет, наказания, ефекти, подаръци и размяна, карти късмет, whisper, мисии, пиене с алтернатива, мини игри); класиране при равенство.
- **server** (`go test`): валидация на всички типове съдържание; rate limiter (отделни броячи за всеки endpoint).

End-to-end smoke тест срещу работещо API (41 проверки — регистрация/вход, валидация, собственост и права, библиотека, любими/копиране/доклад, конфигурации, идемпотентно създаване на сесия, 409 при конфликт, идемпотентни събития, изтриване на профил):

```bash
just test-api
```

Тестът създава и изтрива двама временни потребители. Регистрацията е ограничена до 5 на минута от IP, затова между две пускания изчакайте минута.

## Ограничения и бъдещи стъпки

- **Няма multiplayer** — едно устройство за цялата компания; няма стаи/QR код или телефон за всеки играч.
- **Подаръците са физически** — приложението само ги разпределя и отбелязва, не управлява реални награди.
- **Сървърът не изпълнява engine-а** — валидира структура, размер, собственост и версии, но правилата на играта се изпълняват в браузъра. За локална игра на едно устройство това е достатъчно.
- **Броячът „изиграна“** на готова игра се увеличава само при собствени конфигурации.
- **Rate limiting е в паметта** на процеса — при няколко инстанции е нужен общ store (напр. Redis).
- **Модерацията е базова** — докладване + скриване от администратор; няма автоматичен филтър.
- Звуците са синтезирани (WebAudio); няма музика/файлове.
- Работи само локално — няма production конфигурация (nginx, HTTPS, deploy).
